# MT3 Music Transcription in Colab

Этот репозиторий содержит исправленную версию ноутбука MT3 для автоматической транскрипции музыки в Google Colab.

Авторы - https://github.com/magenta/mt3

## Использование

1. Откройте ноутбук по ссылке:  


2. Выполните ячейки по порядку

## Важно

- Перед началом убедитесь, что выбран **GPU** (Runtime → Change runtime type → T4 GPU).
- в логах могут быть ошибки - это нормально
